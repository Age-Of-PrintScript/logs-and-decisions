### Creación del proyecto y organización por modulos
Se creo el proyecto gradle y lo separamos en muchos modulos porque me re copo. 

```text
printscript/
├── lexer/
├── parser/
├── interpreter/
├── tokens/
├── ast/
└── domain/
```
### Lexer
toda la logica interna del lexer, del automata, etc. Expone la interfaz:
```kotlin
interface Lexer {
    fun tokenize(source: String): List<Token>
}
```
### Parser
Parser y automata interno. Expone: 
```kotlin
interface Parser {
    fun parse(tokens: List<Token>): Program
}
```
### Interpreter
interpreter y su logica interna. ❌ Sin definir su interfaz

### tokens
En este paquete va todo el **lenguaje** compartido entre el lexer y el parser. 
Entre ellos se hablan En lenguaje de tokens y todo eso asi que ambos dependen de este modulo
La clase tokens, token types y todo eso va aca

### ast
En este paquete va todo el **lenguaje** compartido entre el interpreter y el parser. 
Entre ellos se hablan En lenguaje de ast y expressions y todo eso asi que ambos dependen de este modulo
La Interfaz AST, los tipos, el program y todo eso va acá

### Domain
Todo lo que sea logica general de todo el lenguaje y que todos esten "acoplados" a eso.
